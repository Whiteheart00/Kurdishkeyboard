6. Important Notes for Google Studio AI / Developers
================================================================================

- The actual gesture detection and action execution logic is heavily obfuscated
  (R8 full mode). Classes that perform the real work are in "defpackage" package
  with short names (a, b, c, etc.).

- SwipeAction is the central enum. When a swipe is detected in a certain Direction,
  the corresponding SwipeAction (loaded from preferences) is executed.

- Directions support 8-way detection (including diagonals: UP_LEFT, UP_RIGHT, etc.).

- Space bar and Delete key have dedicated swipe actions (premium features in some cases).

- Thresholds (distance + velocity) control how sensitive the swipe detection is.

- This is based on FlorisBoard architecture, customized for Kurdish keyboard
  (package: com.goran.kurdikeyboard).
